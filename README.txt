KIM SUN - WEBSITE NỘI DUNG MÃ HÓA

1. Tải toàn bộ các file trong thư mục này lên thư mục gốc của GitHub Pages.
2. Không tải 3 file HTML gốc lên repository.
3. Không đổi tên các file .dat.
4. Mật khẩu đăng nhập: mật khẩu bạn đã yêu cầu.
5. robots.txt và thẻ noindex đã được thêm để yêu cầu công cụ tìm kiếm không lập chỉ mục.

LƯU Ý:
- GitHub Pages là hosting tĩnh, không có đăng nhập máy chủ.
- Nội dung đã được mã hóa AES-GCM và chỉ giải mã trong trình duyệt sau khi nhập đúng mật khẩu.
- Người ngoài vẫn có thể thấy rằng website có các file dữ liệu mã hóa, nhưng không đọc được nội dung nếu không có mật khẩu.
- Mật khẩu có thể bị dò thử nếu quá yếu hoặc bị chia sẻ.
